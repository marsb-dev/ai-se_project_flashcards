# Project 1: Flashcard app



## Project Description: Collection of flashcards related to programming topics. The user is able to flip through cards with questions and answers.

## Deployment and System Requirements: The user only needs a working computer with a browser and an internet connection.

## Features:
* Decks
* Flippable carousel
* Open deck view
* Deck and card deletion confirmation pop-up
* Responsive design for smaller screens (mobile and tablet)

## Techonologies used:
* Laptop
* VS Code
* ChatGPT Luna 6
